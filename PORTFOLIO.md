# Portfolio Case Study

## Project Summary

Ideal Cannabis is a premium, image-led website concept for an Oregon craft cannabis producer. The project brings brand strategy, original product photography, editorial design, responsive front-end development, merchandising content, and production deployment into one cohesive customer and wholesale experience.

## Challenge

Craft flower quality is sensory and difficult to translate online. The site needed to communicate cultivation intent and product distinction without falling into familiar cannabis visual clichés, while still helping consumers find products and giving dispensary buyers useful commercial detail.

## Approach

- Led with original macro and cultivation photography as visual proof of quality.
- Paired high-contrast editorial typography with a restrained forest-and-cream palette.
- Organized each cultivar around lineage, potency, terpenes, flavor, aroma, effect, and available formats.
- Designed a single lightweight experience that feels multi-page but deploys as a resilient static site.
- Added repository documentation, browser QA, social metadata, and a stable public deployment for portfolio sharing.

## Deliverables

- Brand and content direction
- Art direction and photography presentation
- Responsive UI and interaction design
- Vanilla HTML, CSS, and JavaScript implementation
- Product catalog, filters, detail dialogs, and wholesale flow
- GitHub documentation and Vercel deployment
