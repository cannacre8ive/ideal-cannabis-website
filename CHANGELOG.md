# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning.

## [1.0.0] — 2026-09-02

### Added

- Production-ready static Vercel configuration and release audit.
- Local copies of all nine supplied photographs.
- Canonical, robots, Open Graph, Twitter Card, theme, and favicon metadata.
- Desktop, mobile, and 1200 × 630 social preview screenshots.
- Product, roadmap, design, user-flow, architecture, testing, contribution, attribution, and portfolio documentation.
- Visible keyboard focus, skip navigation, keyboard-operable strain cards, dialog semantics, and reduced-motion support.

### Changed

- Replaced third-party Wix image hotlinks with versioned local assets.
- Added real hash destinations to client-side navigation links.
- Improved mobile navigation state announcements.
- Refreshed desktop, mobile, and social screenshots from the stable production origin.

### Fixed

- Restored keyboard access to interactive navigation and strain-detail controls.
- Exposed dialog and mobile-menu state to assistive technology.
